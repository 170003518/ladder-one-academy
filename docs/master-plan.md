# LADDER ONE ACADEMY — Master Plan & Build Outline

*Planning document only. Nothing is built yet. This is the blueprint we'll refine before any code is written.*

---

## 1. Vision in one sentence

Take someone from zero knowledge to passing the NREMT-EMT, the Florida Firefighter I/II state exams, and the NREMT-Paramedic — one rung at a time — using whatever way of learning actually makes the material stick for them.

**Non-negotiables**
- Zero → certified. No assumed prior knowledge.
- Multiple ways to learn every concept. If one doesn't click, another is one tap away.
- Retention over cramming. Spaced repetition and active recall are built in, not bolted on.
- Gated progression: **EMT → Fire → Paramedic.** Fire stays locked until EMT is complete; Paramedic stays locked until Fire is complete.
- Simple to use. A first-time learner should never wonder "what do I do next?"
- Everything branded and print-ready: tests, worksheets, note cards.

## 2. Name & Branding

### Name: **Ladder One Academy**

Why it works:
- "Ladder" = a fire-service icon *and* the whole idea of the program: climb rung by rung.
- "One" = Ladder 1, the classic first-due company designation. Also "one platform for the whole path."
- Reads professionally on a certificate, a note card, or an app icon.
- Short enough to say, brand as **L1A**, and abbreviate on cards.

Tagline options (pick one):
- **"Every rung. Every call."**
- "Climb to certified."
- "From zero to on-duty."

### Tier naming (the three rungs)
| Tier | Name | Unlocks after |
|---|---|---|
| 1 | **Rung 1 — EMT** | Available from day one |
| 2 | **Rung 2 — Fire** | EMT tier completed |
| 3 | **Rung 3 — Paramedic** | Fire tier completed |

## 3. The Learner Journey (what it feels like to use)

1. **Onboarding (5 min):** "Where are you starting from?" → total beginner / in a class now / retesting. Pick a target exam date. Pick how you like to learn (read, listen, watch, do, quiz). This sets the default learning mode but never hides the others.
2. **Home = the Ladder.** One screen. The three rungs, your current position, today's plan, and one big button: *Continue.* Locked rungs show *what* is inside them and *why* they're locked ("Complete EMT to unlock Fire").
3. **Inside a tier: Modules → Lessons → Concepts.** Modules mirror the real exam blueprint so nothing is studied that isn't tested, and nothing tested is skipped.
4. **Each lesson follows the same loop:** Learn it (your way) → Check it (quick quiz) → Lock it in (cards added to your spaced-repetition deck) → Prove it (module exam).
5. **Daily plan is generated automatically:** cards due today + the next lesson + a short mixed-review quiz. 20–40 minutes. Streaks are tracked but framed as "shifts worked," not guilt.
6. **Exam Readiness meter:** a single 0–100 score per tier built from module exam scores, card retention, and full-length practice exam results. Turns green when you're statistically ready.
7. **Tier completion = a certificate page** (branded, printable) and the next rung lights up.

## 4. Curriculum Maps

> All three blueprints should be re-verified against the current NREMT and Florida BFST standards before content is written — they get updated.

### Rung 1 — EMT (aligned to NREMT-EMT domains + National EMS Education Standards)
1. **Preparatory & Foundations** — EMS systems, roles, safety, wellness, legal/ethical, documentation, communication, radio reports, medical terminology, anatomy & physiology, pathophysiology basics, lifespan development.
2. **Airway, Respiration & Ventilation** — anatomy, assessment, OPA/NPA, suction, oxygen delivery, BVM, CPAP basics, respiratory emergencies.
3. **Patient Assessment** — scene size-up, primary/secondary assessment, vitals, history taking (SAMPLE/OPQRST), reassessment.
4. **Cardiology & Resuscitation** — cardiac emergencies, CPR/AED, ROSC, shock.
5. **Medical** — neuro, endocrine (diabetes), allergic reactions/anaphylaxis, toxicology, abdominal/GI, GU/renal, psychiatric/behavioral, hematology, immunology, infectious disease, gynecology.
6. **Trauma** — bleeding & shock, soft tissue, burns, musculoskeletal, head/spine, chest/abdominal, multi-system, environmental (heat/cold/drowning/bites).
7. **Special Populations** — obstetrics & neonatal, pediatrics, geriatrics, patients with special challenges.
8. **EMS Operations** — ambulance ops, lifting/moving, gaining access, MCI/triage, hazmat awareness, ICS/NIMS, terrorism/WMD basics.
9. **Pharmacology (EMT scope)** — the assist/administer list: oxygen, oral glucose, aspirin, epinephrine auto-injector, naloxone, nitroglycerin (assist), MDI (assist), activated charcoal (where applicable).
10. **Psychomotor Skills Prep** — the NREMT/Florida skill sheets as step-by-step checklists with common-fail points.
11. **Exam Prep Block** — how the adaptive NREMT works, test-taking strategy, full-length simulations.

### Rung 2 — Fire (Florida Firefighter I & II / Minimum Standards, aligned to NFPA 1001 & IFSTA Essentials)
1. Fire service orientation, history, organization, safety & health
2. Fire behavior & building construction
3. PPE, SCBA & air management
4. Portable extinguishers
5. Ropes, knots, webbing
6. Ground ladders (yes, the brand gets to have fun here)
7. Forcible entry
8. Ventilation
9. Water supply, hose, nozzles, fire streams, hydraulics/pump basics
10. Fire control (structural, vehicle, wildland, flammable liquids/gas)
11. Search & rescue, firefighter survival, RIT/Mayday
12. Salvage & overhaul
13. Loss control, fire protection systems (sprinklers, alarms, standpipes)
14. Hazmat Awareness & Operations
15. Communications, incident command, pre-incident planning, fire prevention & public education
16. Skills checklists for the Florida practical (state skills sheets)
17. State written exam prep block

### Rung 3 — Paramedic (aligned to NREMT-Paramedic domains)
1. **Advanced Preparatory** — A&P in depth, pathophysiology, acid–base, fluids/electrolytes, research, public health, medical-legal at the ALS level.
2. **Pharmacology** — pharmacokinetics/dynamics, the full ALS drug list, drug math (the #1 place students fail — gets its own worksheet engine), medication administration routes, IV/IO access.
3. **Airway (advanced)** — supraglottic, ETI, RSI/DAI concepts, capnography, ventilators, surgical airway.
4. **Cardiology** — 12-lead interpretation (its own sub-course with hundreds of strips), ACLS algorithms, pacing/cardioversion/defib, STEMI recognition, heart failure, aortic emergencies.
5. **Medical** — every EMT medical topic at depth plus sepsis, endocrine crises, neuro (stroke scales, seizures), renal, hematologic, immunologic.
6. **Trauma** — advanced hemorrhage control, chest decompression, TBI/spinal management, burns fluid resuscitation, trauma triage & destination decisions.
7. **Special Populations** — OB complications & delivery, neonatal resuscitation (NRP), PALS, geriatrics, bariatrics, home-care patients.
8. **Operations** — MCI/ICS leadership, air medical, crime scene, rescue awareness, hazmat medical care.
9. **Clinical Decision Making & Critical Thinking** — scenario-based reasoning, differential diagnosis, treatment plans.
10. **Exam prep block + full ALS scenario simulations.**

## 5. Learning Modes (the "if one way doesn't click" engine)

Every concept is stored once and rendered in up to **8 modes**. The learner can flip between them on any lesson.

| Mode | What it is | Best for |
|---|---|---|
| **Read** | Clean textbook-style explanation, layered: *Plain English → Standard → Deep dive* | Readers, first pass |
| **Explain Like I'm New** | Analogy-first version ("Preload is how full the balloon is before you squeeze it") | When the standard text bounces off |
| **See It** | Diagrams, labeled anatomy, flowcharts, algorithm trees, ECG strips, equipment images | Visual learners, procedures |
| **Hear It** | Audio narration of the Read mode (for driving / gym) | Commuters, audio learners |
| **Do It** | Interactive: drag-and-drop assessments, click-the-anatomy, build-the-algorithm, virtual patient scenarios | Kinesthetic learners, procedures |
| **Quiz It** | Micro-quizzes with instant *why* explanations for every wrong answer | Active recall |
| **Teach It Back** | Learner types/records their own explanation; the system checks it against key points | Highest retention |
| **Story It** | Short realistic call narrative that walks the concept from dispatch to handoff | Memory hooks, context |

Every mode ends with the same **Key Points box** and the same **note cards**, so switching modes never means losing consistency.

### Retention system
- **Spaced repetition (SM-2 / FSRS style)** deck built automatically from every lesson's key points, drugs, numbers, and skill steps.
- **Interleaved review:** daily quiz mixes topics from earlier modules so nothing decays.
- **Weak-spot detection:** every question is tagged by concept; misses feed a *Focus List* that reshapes the daily plan.
- **Confidence tagging:** learner rates "guessed / unsure / knew it" on every answer — guesses that were right still come back.

## 6. Note Card System

Note cards are a first-class product, not an export.

### Card types
1. **Concept Card** — one idea, front/back, with a one-line "why it matters."
2. **Drug Card** — name, class, indications, contraindications, dose (adult/peds), route, onset, side effects, EMT vs. Paramedic scope flag.
3. **Skill Card** — numbered steps, critical-fail points highlighted in Signal Yellow.
4. **Numbers Card** — vitals ranges by age, GCS, burn %, APGAR, formulas, ECG intervals.
5. **Algorithm Card** — a condensed decision tree (ACLS, stroke, anaphylaxis).
6. **Mnemonic Card** — SAMPLE, OPQRST, DCAP-BTLS, AVPU, etc., with the expansion and a memory image.
7. **Compare Card** — two easily-confused things side by side (COPD vs. CHF, hypo vs. hyperglycemia).

### Two ways cards are made
- **Curated section decks** — every module ships with a professionally laid out deck.
- **Custom generated decks** — learner selects any set of concepts, drugs, or their own Focus List and the system generates a branded deck on the spot.

### Formatting standard (the "looks professional" requirement)
- Sizes: 3×5 in, 4×6 in, and A6. Print layout auto-tiles them onto Letter/A4 with cut guides, front/back aligned for duplex printing.
- Layout: L1A stamp top-left, tier color bar left edge, card type label top-right, module reference in footer, card number for ordering.
- Consistent hierarchy: title, one-sentence summary, body, "High-yield" flag if it's a known exam favorite.
- Output: PDF (print), PNG (share), and digital flip cards in-app.
- Export to Anki/Quizlet format so nobody is locked in.

## 7. Test & Practice Engine

### Question bank
- Target: **EMT 2,500+ · Fire 2,000+ · Paramedic 4,000+** questions at launch, growing.
- Every question has: stem, 4 options, correct answer, *full rationale for every option* (why right, why each wrong), concept tags, difficulty rating, exam-domain tag, source reference.
- Question styles: recall, application, scenario ("You arrive to find…"), image-based (ECG strips, equipment, wounds), calculation (drug math, hydraulics), skill-sequence ordering.

### Test types
| Type | Length | Purpose |
|---|---|---|
| Lesson check | 5–10 | Immediate recall |
| Module exam | 25–50 | Gate to next module |
| Mixed review | 20 | Daily interleaving |
| Focus drill | 10–30 | Only your weak concepts |
| Full simulation | 70–120 (EMT) / 80–150 (Paramedic) / 100 (Fire) | Mirrors real exam feel |
| **Adaptive simulation (NREMT mode)** | Variable | Mimics computer-adaptive difficulty; ends when readiness is established |
| Timed skills-sheet quiz | — | Step ordering & critical criteria |

### Feedback & analytics
- Score by exam domain (matches the NREMT/Florida score report format so it looks familiar).
- Rationale review mode after every test.
- Trend charts: readiness over time, domain heat map, time-per-question.
- **Predicted readiness** feeds the Exam Readiness meter.

### Worksheets
- Printable, branded, tied to each lesson: fill-in-the-blank anatomy, label-the-diagram, drug-math practice sets with answer keys, scenario write-ups, ECG strip sets, hose/hydraulics calculations, knot ID.
- Generated variants so a learner can print a fresh version each time.

## 8. Progression & Gating Rules

- **Lesson complete:** viewed in at least one mode + lesson check ≥ 80%.
- **Module complete:** all lessons complete + module exam ≥ 80% (retake allowed after a 24-hour review period with a fresh question set).
- **Tier complete (EMT / Fire / Paramedic):** all modules complete + two full simulations ≥ 85% + card retention ≥ 90% on the tier deck + skills checklists reviewed.
- **Unlock:** Fire unlocks on EMT completion; Paramedic unlocks on Fire completion.
- **Override:** an "I'm already certified" path lets a licensed EMT verify (self-attest + optional cert upload) to unlock Fire without redoing EMT. Same for Fire → Paramedic. Keeps the ladder honest without punishing people who already climbed a rung elsewhere.
- Locked tiers are **browsable but not openable** — a learner can see the module list and a preview lesson so the goal stays visible.

## 10. Content Production Pipeline

Content is the real work. The software is the easy part.

1. **Blueprint first:** map every NREMT/Florida objective to a concept ID. This is the spine; everything hangs off it.
2. **Concept spec per ID:** key points, common misconceptions, exam-favorite facts, related concepts, prerequisite concepts.
3. **Generate the 8 modes from the spec** (AI-assisted drafts), then **human review against a source text** (IFSTA Essentials, AAOS Emergency Care, Nancy Caroline, current AHA guidelines).
4. **Question writing rules:** every question maps to a concept ID; rationale for all four options is mandatory; scenario questions must be clinically realistic; reviewed by someone certified at that level.
5. **Card and worksheet generation** from the same concept specs so they never drift from the lessons.
6. **Versioning:** guidelines change (AHA every ~5 years, NREMT blueprint periodically). Every content item carries a "reviewed against" date.
7. **Media:** diagram set (original, licensed-clean), ECG strip library, equipment photo set, skill animations. Keep a manifest so nothing copyrighted slips in.

## 11. Technical Architecture (high level — for discussion, not decided)

Given your existing pattern (single-file HTML tools, Cloudflare + GitHub Actions), two viable paths:

**Path A — Extend what you already do:** a static site (HTML/JS, one build per tier) with content stored as JSON/Markdown, deployed on Cloudflare Pages; progress stored locally with optional sync via a lightweight backend (Cloudflare Workers + D1/KV). Fastest to start, aligns with your EMT Learning Tool already built.

**Path B — Proper app:** a web app (React/Svelte) with a backend (Workers or Supabase), auth, cloud progress, multi-device sync, and PDF generation server-side. Needed if this becomes a product for other students.

Recommendation: **start on Path A for your own EMT run beginning January 2027, structured so the content layer is portable to Path B later.** The content format (concept specs, questions, cards as structured data) is the asset — the shell can be rebuilt.

Core building blocks either way:
- **Content store:** structured JSON per concept (text modes, key points, cards, questions, media refs).
- **Progress engine:** lesson/module/tier state, gating logic, SRS scheduler.
- **Test engine:** question selection (random, domain-weighted, adaptive), scoring, rationales, analytics.
- **Card renderer:** HTML → PDF with print tiling; PNG export.
- **Worksheet generator:** template + variable pools → fresh printable.
- **Media library:** diagrams, ECG strips, images, audio.
- **Branding layer:** one theme file (colors, logo, tier bars) that every renderer pulls from.
